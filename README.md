Task 4: Common Network Security Threats

Objective

This repository contains a research report on common network security threats, including:

* Denial of Service (DoS) attacks
* Man-in-the-Middle (MITM) attacks
* Spoofing attacks

The report explains how these attacks work, their impact on organizations, real-world examples, and mitigation strategies.
